# ELEMENTUM
# 🧪 Interactive Periodic Table

A modern, interactive **Periodic Table web application** built with HTML, CSS, and JavaScript.
This project focuses on **beautiful UI, smooth animations, and advanced interactivity**, including 3D visualizations and a quiz system.

---

## 🚀 Features

### 🌗 Theme System

* Dark mode (default) 🌙
* Light mode ☀️
* Smooth transitions between themes
* User preference saved with localStorage

---

### 🧪 Periodic Table

* Clean grid layout (default view)
* Each element displays:

  * Symbol
  * Atomic number
* Click on an element to view:

  * Name
  * Atomic mass
  * Category (family)

---

### 🌈 Color-Coded Families

Each chemical family has a unique color:

* 🔴 Alkali metals
* 🟠 Alkaline earth metals
* 🔵 Transition metals
* 🟢 Metalloids
* 🟣 Nonmetals
* 🌸 Noble gases

Includes glow effects and consistent styling.

---

### 🌐 Multiple Visualization Modes

#### 🧱 Grid

* Classic periodic table layout

#### 🌍 Sphere (3D)

* Built using Three.js
* Elements arranged in a rotating sphere
* Smooth animations

#### 🧬 Helix

* Spiral layout
* Animated 3D-like effect

---

### 🎮 Quiz System

* Random element-based questions
* Example:

  > What is the symbol of Oxygen?
* Instant feedback:

  * ✅ Correct
  * ❌ Incorrect + correct answer
* Continuous questions
* (Optional) Score tracking

---

### ✨ Animations

* Hover → scale + glow
* Click → smooth info panel
* Page load → fade-in
* View switching → animated transitions
